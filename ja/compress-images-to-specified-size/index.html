    画像を特定のファイル サイズに圧縮する必要があるのはなぜですか?


    昨年の初めに、私の友人 (ImagesTool.com の開発者) が私に助けを求めてきたのですが、彼女は、Web サイトで電子パスポート申請を提出したときに、画像を必要とする肖像写真の仕様の 1 つを見たと言っていました。ファイルのサイズ制限は 30Kb ～ 80Kb です。


    これは非常にわかりにくいです。従来の画像圧縮ツールでは、この範囲内でそれほど正確に制御することができませんでした。そこで、このツールを時間をかけて作成しました。jpg 画像ファイルのサイズを、設定された上限内で非常にうまく制御できます。


    たとえば、先ほど述べた電子パスポート要件の場合、「以下」を 80 に設定するだけで済みます。圧縮された結果は 80Kb に非常に近くなり、80Kb を超えることはありません。


    同じ古いルールで、無料で使用でき、バッチで圧縮できます。このツールはブラウザでローカルに実行され、プライバシーとセキュリティを保護します。インポートされた
    ファイル タイプをサポートしています: jpg、jpeg、png、gif、webp、avif、ico、bmp、svg
    ファイル形式: jpg、 webp

    結論

    画像の幅と高さを同時に調整する必要がある場合は、「 画像のサイズ変更」 を使用できますが、多くの Web サイト (通常は政府機関の Web サイト) で縦長の画像サイズを調整するため、より専門的なツール (Photoshop など) を使用することをお勧めします。写真の仕様が厳しいため、写真内のアバターの位置については、Web サイトの要件に合わせてより慎重に画像を調整する必要があります。

    調整したら、最高品質の jpg 画像をエクスポートし、このページに戻って指定したサイズに圧縮します。あなたの人生に幸あれ！

    圧縮処理が失敗したことを示すメッセージがページに表示されるのはなぜですか? (何か問題が発生しました!)


    😊 このエラーが発生する確率は 5% のみであり、修正することができますので、ご安心ください。

    おそらく、インポートした画像のサイズが「超えない」に設定されている値と違いすぎるためです。

    たとえば、3000x4000 の jpg をインポートした後、「超えない」を 50Kb に設定します。これはほとんどの場合不可能です。100Kb に設定すると、圧縮エラーが発生する可能性もあります。

    適切な値は 500kb から 2000kb の間です。


    このエラーを修正する別の方法として、サイズを変更する方法があります。上記の例では、3000x4000 の jpg をインポートした後、それを 50 以下に設定し、同時にエクスポートされた画像の幅を次のように設定します。 「幅の変更」を設定すると500pxになるので、この設定がより合理的です。

    QA

    >

    指定したファイルサイズの画像の一括圧縮はサポートされていますか?

    サポートされています。固定サイズにバッチ圧縮する場合、インポートされる画像のサイズの差が大きすぎないように注意する必要があります。たとえば、2000x3000px と 1500x2200px の画像のバッチは問題ありませんが、インポートされたサイズが大きい場合は、たとえば、2000x2000px や 100x200px などの画像のバッチはまとめて圧縮するのには適していません。指定したサイズに一括圧縮するには、同様のサイズの画像を選択するようにしてください。
    たとえば、2000x2000px と 100x200px の画像をまとめて横幅 100px に調整する場合など、画像サイズ調整も設定していなければ問題ありません。

    >

    圧縮された画像の品質が可能な限り高いままであることを保証できますか?

    はい、このツールは画像サイズを圧縮する際に、設定された「超えない」値を超えないようにします。つまり、指定されたサイズ内で可能な限り高画質を維持できることになります。たとえば、「超えない」が 100Kb に設定されている場合、圧縮は 99Kb または 92Kb になります。特定の画像ファイル サイズは、ImagesTool 圧縮ツールによって自動的に完成されます。
